# Code of conduct

## The standard

Be decent. Assume the person on the other end is trying to do good work with incomplete
information, because that is usually what is happening.

Concretely, in this repository:

- **Critique the work, not the person.** "This has two implementations of one idea" is useful. "You
  clearly did not read anything" is not, and it is also usually wrong.
- **Say what you would accept.** A review that only says no costs somebody a day.
- **Nobody owes you a fix.** This is a project people work on, not a service they provide to you.
- **No harassment, of any kind**, in issues, pull requests, commit messages or anywhere else that
  carries this project's name. That includes personal attacks, sexualised language, deliberate
  misgendering, and dragging someone's identity into a technical argument.

## Scope

This applies in the repository and in any space where you are representing the project.

## Enforcement

Report a problem privately to the maintainers through GitHub — open a private security advisory if
there is no other private channel, and say it is a conduct report rather than a vulnerability.
Reports are read by the maintainers and not shared further than necessary to deal with them.

Maintainers may edit, hide or delete comments, close pull requests, and block accounts. Bans are a
last resort and are explained to the person banned.

This document is deliberately short and unborrowed. It is not a substitute for the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which is
longer, more careful, and worth reading if you want the full version of what "be decent" means in
practice.
